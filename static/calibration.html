Шаг 1 — Смартфон
Используется для базы данных калибровок
Или выберите из своего профиля
ARP (точка отсчёта антенны) всегда принимается как верхняя грань смартфона. Смещения редуцирования измеряются рулеткой от маркированной точки до верхней грани.
Шаг 2 — Режим калибровки
Полная
Полная калибровка
8 сеансов: 4 вертикальных + 4 горизонтальных.
Все три компоненты фазового центра.
Горизонт.
Только горизонталь
4 вертикальных сеанса.
Горизонтальные компоненты без опорной точки.
Быстрая
Быстрая
1 вертикальный сеанс + опорная точка.
Валидность 12 часов, ориентация — строго на север.
Шаг 3 — Опорная точка
Геодезическая марка
Известные координаты точки (B, L, H) — каталог, геодезическая съёмка
ГНСС-приёмник
Статические наблюдения приёмника ≥ 4 часов на произвольной точке
Без опоры
Только горизонтальные компоненты (из симметрии ориентаций)
Загрузите RINEX-файл наблюдений приёмника. Рекомендуется ≥ 4 часов наблюдений. Файл будет обработан методом PPP для получения координат точки.

Перетащите RINEX-файл или нажмите для выбора

Шаг 4 — Элементы редуцирования
Измерьте рулеткой расстояния от маркированной точки до верхней грани смартфона (ARP). Используйте схему ниже для определения знаков смещений.
ARP выше марки → h > 0
ARP восточнее марки → dE > 0
ARP севернее марки → dN > 0
